# 属性文档模板

## 属性分级标准

**A 级**（满足任一条即为 A 级，需要写详细档案）：
- 在 Tick / 主循环中被读写
- 被 ≥ 2 个函数读写
- 是模块对外暴露的状态载体
- 是缓存类字段（名称含 Cache / Cached / Last / Pending）
- 是状态机字段（枚举类型）
- 是容器类字段（Map / Array / Set / Queue）

**B 级**：其他属性，用简表记录。

---

## A 级属性档案（六要素模板）

> 精读前置要求：必须 grep 该属性名，列出所有读写位置，区分"="赋值与读取访问，
> 再查看至少 1 处写入上下文和 1 处读取上下文，才能填写以下内容。

```markdown
##### `属性名` (类型)

- **用途**：说明这个字段在业务上的真实作用，不是字段名的字面翻译
- **生命周期**：何时被初始化、何时失效、帧内是只读还是可写
- **写入位置**：
  - `函数名()` (文件路径:行号) — 写入时机和原因
- **读取位置**：
  - `函数名()` (文件路径:行号) — 读取后用于做什么
- **典型值/约定**：取值范围、单位、特殊边界值的含义
- **相关字段**：与哪些字段配套使用，是否需要同步更新
```

### 填写示例

```markdown
##### `CachedViewProjectionMatrix` (FMatrix)

- **用途**：缓存当前帧的视图投影矩阵（World → Clip Space），用于将 NPC 世界坐标
  投影到屏幕空间做可见性判断，避免每次判断都重新从 CameraSystem 取矩阵
- **生命周期**：每帧 Tick 开头由 `CacheFrustumData()` 重新写入，帧内其他代码只读
- **写入位置**：
  - `CacheFrustumData()` (NPCDataManager.cpp:1234) — 从 CameraGameSystem 取
    最新视图矩阵后写入，与 CachedFrustumData 同帧刷新
- **读取位置**：
  - `IsPointVisible()` (NPCDataManager.cpp:2156) — 将候选点乘以矩阵得到 NDC 坐标
  - `IsNPCDataInFOV()` (NPCDataManager.cpp:2301) — 屏幕空间裁剪测试
- **典型值/约定**：行主序矩阵；W 分量需做齐次除法；W ≤ 0 表示点在相机后方需剔除
- **相关字段**：与 `CachedFrustumData`、`CachedViewProjectionData` 配套，三者必须同帧更新
```

## B 级属性简表

> **精读前置要求**：即使是 B 级属性，也**必须** grep 字段名查看至少 1 处使用场景，
> 才能写"说明"列。禁止仅凭字段名字面翻译。

| 字段 | 类型 | 说明 |
|------|------|------|
| `字段名` | 类型 | 至少包含两类信息：用途 / 赋值时机 / 读取场景 |

### 合格示例

| 字段 | 类型 | 说明 |
|------|------|------|
| `UniqueID` | int32 | NPC ID 自增计数器，初值 10000，每次 `SpawnNPC()` 后自增 1，确保全局唯一 |
| `bInitialized` | bool | 初始化完成保护标志，`OnInitData()` 末尾置 true；Tick 开头检查若为 false 直接 return，防止依赖项未就绪时执行 |

### 禁止示例

| 字段 | 类型 | 说明 |
|------|------|------|
| `CachedViewProjectionMatrix` | FMatrix | 视图投影矩阵 |  ← 字面翻译，不合格
| `bInitialized` | bool | 是否初始化 |  ← 无用途、无时机，不合格
