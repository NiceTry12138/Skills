# 复杂算法分析模板

## 触发条件

当函数涉及以下任一情况时，必须单独写一节深入分析：

- 数学 / 几何 / 数值计算
- 算法（排序、搜索、图、DP、贪心、加权分配等）
- 状态机 / 协议解析
- 并发 / 锁 / 调度逻辑
- 加密 / 哈希 / 编解码
- 多阶段流水线（分帧处理、异步加载链等）

## 示例：透明度继承算法

### 透明度继承算法

**1. 算法原理**
当一个新的淡出动画打断当前进行中的淡出动画时，为避免透明度跳变，需要根据当前
透明度反推新动画的"已执行时间"，从当前值平滑过渡到新目标值。

公式：`ElapsedTime_new = (CurrentOpacity - StartOpacity) / (TargetOpacity - StartOpacity) × TotalTime`

**2. 执行步骤**
1. 取当前透明度 `CurrentOpacity`
2. 以 `CurrentOpacity` 为新动画的起始值
3. 用公式计算继承进度，得到 `ElapsedTime_new`
4. 从 `ElapsedTime_new` 处开始播放新动画

**3. 数值走查示例**

场景：FadeOut（1.0→0.0，2 秒）执行到 0.5 秒时（透明度=0.75）被 CollisionFade
（1.0→0.5，1 秒）打断。

- 新动画：StartOpacity=1.0，TargetOpacity=0.5，TotalTime=1 秒
- 当前透明度：0.75
- 继承进度：(0.75 - 1.0) / (0.5 - 1.0) = (-0.25) / (-0.5) = 50%
- ElapsedTime_new = 50% × 1 秒 = 0.5 秒
- 结果：新动画从其时间轴的 0.5 秒处开始播放（已"虚拟执行"50%），此刻按新动画公式算出的透明度恰好是 0.75，与当前值匹配，后续 0.5 秒内从 0.75 平滑下降到 0.5，无跳变

**4. 复杂度与边界条件**
- 时间复杂度：O(1)
- 边界：TargetOpacity == StartOpacity 时分母为 0，需提前检查，直接设 ElapsedTime_new = 0
